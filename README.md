# openapi2html

Превращает OpenAPI-спецификацию (YAML или JSON) в одну HTML-страницу, которую удобно читать: методы, поля, примеры, коды ответов, авторизация.

Результат - один `.html` файл без зависимостей. Открывается в любом браузере, можно отправить коллегам или приложить к задаче.

## Что умеет

- OpenAPI 3.0 и 3.1
- внешние `$ref` (`./common.yaml#/components/responses/BadRequest`) подтягиваются из файлов рядом со спецификацией; если файла нет, страница всё равно соберётся
- таблицы полей с вложенностью (`items[].author.name`), `allOf` / `oneOf` / `anyOf`, enum, ограничения, `readOnly` / `writeOnly`
- расшифровка enum из `x-enum-descriptions` / `x-enum-varnames`
- переключатель примеров и вид «Таблица» для массивов объектов
- пример генерируется по схеме, если в спецификации его нет
- блок «Вызов»: готовый curl и проверка тела запроса по схеме прямо на странице
- раздел «Замечания»: неразрешённые ссылки и примеры, которые не проходят проверку по своей схеме
- поиск по методам, группировка по тегам, светлая и тёмная тема

## Установка

**Без Python (Windows):** скачайте [`bin/openapi2html.exe`](bin/openapi2html.exe). Больше ничего не нужно.

**С Python 3.8+:**

```bash
pip install -r requirements.txt
```

## Запуск

**Проще всего:** перетащите `.yaml` файл на `openapi2html.exe` (или на `openapi2html.bat`, если стоит Python). Рядом появится `.html` и сразу откроется в браузере.

**Из командной строки:**

```bash
openapi2html.exe spec.yaml
```

или

```bash
python openapi2html.py spec.yaml
```

| Параметры | Что делает |
|---|---|
| `spec.yaml` | создаёт `spec.html` рядом со спецификацией |
| `spec.yaml -o docs/api.html` | сохраняет в указанный файл |
| `a.yaml b.yaml` | обрабатывает несколько файлов |
| `spec.yaml --open` | открывает результат в браузере (exe делает это сам) |
| `spec.yaml --no-open` | не открывать браузер |

В консоль выводятся неразрешённые `$ref`, чтобы сразу было видно, каких файлов не хватает.

## Пример

В папке `examples` лежит демо-спецификация с внешним файлом и намеренно ошибочным примером:

```bash
python openapi2html.py examples/library.yaml --open
```

## Устройство

| Файл | Назначение |
|---|---|
| `openapi2html.py` | читает YAML/JSON, разрешает внешние `$ref`, собирает HTML |
| `template.html` | разметка и стили страницы |
| `renderer-core.js` | таблицы схем, примеры, генерация и проверка по схеме |
| `renderer-page.js` | разделы страницы, навигация, поиск, curl |
| `openapi2html.bat` | запуск перетаскиванием файла (нужен Python) |
| `build_exe.bat` | сборка `bin/openapi2html.exe` |
| `bin/openapi2html.exe` | готовая программа для Windows |

Компоненты из внешних файлов (`common.yaml#/components/schemas/Error`) переносятся в `components` итоговой спецификации с сохранением имени, остальные ссылки подставляются на место.

## Сборка exe

```bash
build_exe.bat
```

Скрипт создаёт окружение `.venv`, ставит PyInstaller и кладёт результат в `bin/openapi2html.exe`. Шаблон и JS зашиваются внутрь exe, поэтому после правок в `template.html` или `renderer-*.js` exe нужно пересобрать.

## Ограничения

- Swagger 2.0 не поддерживается - сначала сконвертируйте в OpenAPI 3 (например, https://converter.swagger.io)
- страница не отправляет запросы, только формирует curl
- шрифты Golos Text и JetBrains Mono грузятся из Google Fonts; без интернета используются системные
