# Swagger Compiler

Программа для Windows, которая показывает OpenAPI-спецификацию (YAML или JSON) в виде понятной документации: методы, поля, примеры, коды ответов, авторизация. Готовую страницу можно сохранить в один `.html` файл и отправить коллегам.

## Возможности

**Окно программы**
- открытие файла кнопкой, `Ctrl+O` или перетаскиванием в окно
- список недавних файлов на стартовом экране
- автообновление: поправили YAML в редакторе, страница обновилась сама
- сохранение в HTML (`Ctrl+S`), открытие в браузере, счётчик замечаний
- понятная ошибка с номером строки, если YAML сломан

**Страница документации**
- OpenAPI 3.0 и 3.1
- внешние `$ref` (`./common.yaml#/components/responses/BadRequest`) подтягиваются из файлов рядом со спецификацией; если файла нет, страница всё равно соберётся
- таблицы полей с вложенностью (`items[].author.name`), `allOf` / `oneOf` / `anyOf`, enum, ограничения, `readOnly` / `writeOnly`
- расшифровка enum из `x-enum-descriptions` / `x-enum-varnames`
- переключатель примеров и вид «Таблица» для массивов объектов
- пример генерируется по схеме, если в спецификации его нет
- блок «Вызов»: готовый curl и проверка тела запроса по схеме
- раздел «Замечания»: неразрешённые ссылки и примеры, которые не проходят проверку по своей схеме
- поиск по методам (`Ctrl+F`), группировка по тегам, светлая и тёмная тема

## Установка

Скачайте [`bin/SwaggerCompiler.exe`](bin/SwaggerCompiler.exe) и запустите. Python не нужен.

Для работы окна нужен системный компонент WebView2 - в Windows 10 и 11 он обычно уже есть.

При первом запуске Windows может показать «Windows защитил ваш компьютер», потому что программа не подписана: **Подробнее** -> **Выполнить в любом случае**.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | открыть файл |
| `Ctrl+S` | сохранить HTML |
| `F5` | перечитать файл |
| `Ctrl+F` | поиск по методам |

Файл также можно перетащить на значок `SwaggerCompiler.exe` - программа сразу его откроет.

## Командная строка

Для автоматизации есть консольный вариант (нужен Python 3.8+):

```bash
pip install -r requirements.txt
python openapi2html.py spec.yaml
```

| Параметры | Что делает |
|---|---|
| `spec.yaml` | создаёт `spec.html` рядом со спецификацией |
| `spec.yaml -o docs/api.html` | сохраняет в указанный файл |
| `a.yaml b.yaml` | обрабатывает несколько файлов |
| `spec.yaml --open` | открывает результат в браузере |

Окно программы из исходников: `python app.py [spec.yaml]`.

## Пример

В папке `examples` лежит демо-спецификация с внешним файлом и намеренно ошибочным примером - откройте `examples/library.yaml` в программе.

## Устройство

| Файл | Назначение |
|---|---|
| `app.py` | окно программы (pywebview): диалоги, недавние файлы, автообновление |
| `app_ui.html` | интерфейс окна: панель, стартовый экран, ошибки |
| `openapi2html.py` | читает YAML/JSON, разрешает внешние `$ref`, собирает страницу; консольный режим |
| `template.html` | разметка и стили страницы документации |
| `renderer-core.js` | таблицы схем, примеры, генерация и проверка по схеме |
| `renderer-page.js` | разделы страницы, навигация, поиск, curl |
| `assets/app.ico` | иконка, рисуется `tools/make_icon.py` |
| `build_exe.bat` | сборка `bin/SwaggerCompiler.exe` |

## Сборка exe

```bash
build_exe.bat
```

Скрипт создаёт окружение `.venv`, ставит зависимости и PyInstaller, рисует иконку и кладёт результат в `bin/SwaggerCompiler.exe`. Интерфейс, шаблон и JS зашиваются внутрь exe, поэтому после правок их нужно пересобрать.

## Ограничения

- Swagger 2.0 не поддерживается - сначала сконвертируйте в OpenAPI 3
- страница не отправляет запросы, только формирует curl
- шрифты страницы грузятся из интернета; без сети используются системные
